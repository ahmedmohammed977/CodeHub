CodeHub Report

1. Project Topic
My project is a website for a technology academy called CodeHub.
It offers courses like Web Development, Python, and Linux Security.

2. Project Purpose
I made this website to practise HTML and CSS and apply what we studied in Web Programming.

3. Technologies
- HTML5
- CSS3
- Bootstrap 5

4. Website Pages

The website has 6 pages:
1. Home: Welcome section and course cards.
2. Courses: Shows the available courses.
3. Instructors: Shows the academy instructors.
4. Schedule: Contains the weekly timetable.
5. Register: Contains the registration form.
6. About: Gives information about CodeHub.

5. What I Used

I used semantic tags, links, images, lists, a table, audio, and a registration form.
In CSS, I used colors, fonts, margins, padding, Flexbox, Grid, positioning, and media queries.
I also used Bootstrap classes for the layout, buttons, forms, and tables.
