CodeHub Project
This is my Web Programming project. I made a website for a training academy called CodeHub.
The website has 6 pages about courses, instructors, schedules, and registration.
I used HTML, CSS, and Bootstrap 5 for the design.

How to Open
1. Extract the ZIP file.
2. Open "index.html" in your browser.
3. Use the menu to move between the pages.
4. You can use Live Server in VS Code too.

The website is a front-end project, so the registration form does not save data.
